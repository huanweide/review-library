# 剧情推进 Agent · 续写要求与字段说明

> 用户原文照抄；不改写、不总结。剧情推进 Agent 直接按这两段执行。

## 续写要求（原文）

```text
<续写要求>
剧情内容分两段，两段都很重要：
前半段：以<stage>素材为骨，按照<user_input说明>的字段语义润色和扩写——把字段翻译成自然的动作、对白、内心活动。不要原样照抄字段，也不要漏掉关键beat。确保<user_input>中的行为动作和被双引号包裹的对话内容在正文出现。
后半段：素材用完之后，顺着剧情流向自然合理地把情节往前延伸一段。不要停在素材末尾收尾，也不要硬拐弯。

写之前先在思维链里回答这两个问题：
1.素材用完后如何继续推进剧情？（找当前未决的悬念 / 在场NPC的initiative / scene里"未结束的线索"）
2.接下来怎么发展最自然有趣（但要合理）？（合理 = 不违反角色性格、世界观和已建立的因果；有趣 = 给一个新动作 / 新选择 / 新信息，不是原地打转）

⚠ 不要把"前半段扩写"和"后半段推进"显式拆成两块——分段是写作思路，不是输出格式。正文要连贯成一段，读起来不能有"扩写完了，开始推进"的接缝。
</续写要求>
```

## user_input 说明（原文）

```text
<user_input说明>
以下字段，你要知道是什么意思：
scene：时间、地点、在场角色、当前线索、有没有人入场或离场。

act（每个在场NPC都会有一组）：
关系：关系=[关系阶段名]直接描述当前实际关系。
now：角色当前正在做什么
beat：角色这轮干了什么、说了什么。
then：紧接着角色又干了什么说了什么。
initiative：角色自己主动开启的新话题或行动。
interplay：NPC之间的互动。

多NPC在场时怎么写
不是每个NPC都需要一样多的笔墨——看这轮谁跟主角互动最多，那个人是焦点。
焦点NPC：beat和台词写细，情绪从动作和节奏里流出来。
非焦点NPC：穿插在焦点NPC的段落间隙里——一个动作、一句话、一个状态就够了。
写法是交叉的，不是排队的：
  ✗ 先写完A的全部反应 → 再写完B的全部反应 → 再写C的 ← 像三段独立的小作文
  ✓ A说了一句话 → B在旁边做了个动作 → A继续 → C插一嘴 ← 像他们真的在同一个空间里
对话超过两个人时：
· 同时说话的只写1-2人交替，其他人用动作反应代替台词。
beat很短的NPC（素材里只有1-2句的），正文里压缩成场景细节：
  ✓ "角落里老张还在擦刀，头也没抬。"
  ✓ "莉娜靠在门框上打了个哈欠。"
  不需要给TA单独开一段。
</user_input说明>
```
