# 提示词研究 · 总目录

这是我的专用研究区，专门啃四件事：**酒馆怎么把提示词拼起来、各家模型什么脾气、提示词怎么写才有人听、技术怎么讲才讲得明白**。

学到的东西全部沉淀在这儿，每天存一点，越攒越厚。

## ★ 体系架构（新内容往对应枝上加，不另起新枝）

这棵树的每一层是**一类问题**，每个枝头是**一条已验证的结论**——每条结论都标了它归在哪一页哪一节。
**以后所有新提炼的内容，先判断它属于哪一层，再往那根枝上加；只在整层缺失时才新建一页。** 这样页面越读越厚、体系越来越紧，不会长成散沙。

```
│   └─ **状态还是这条循环的存档点**（"更新状态"的第二个用途）：决定出事之后**能不能从这里接着走**——★**不能分段承兑的循环，跑得越长越脆**；物证：Agent 运行数据专门留一类记"检查点" → 06 页 §二
│   └─ 人格七层结构（麦基）：欲望→恐惧→矛盾→底线           → 创作/角色人格七层结构法
│   └─ 状态机视角：Agent = 会自己往下走的状态机            → 06 页
│   └─ 多主体三件隔离：输入按"谁该知道"切 / 共享状态≠共享写权限 / 顺序执行靠锚点=逻辑同时 → 06 页 §二
│   └─ 禁令管不住不存在的东西，要改可见性（铁律②结构层）   → 06 页 §二
│   └─ **分工的依据不是工种，是"这条约束要什么能力"**：往前写→生成者 / 算得清→确定性程序 / 回头看→独立核对环节；**别按内容分** → 06 页 §二

│   ├─ 让配置留得住

│   │   └─ 名字/ID 是弱引用，版本升级会断                   → 01 页 §五
│   │   └─ 配置按作用域隔离；分布式批量改有竞态              → 01 页 §五
│   │   └─ 两类后端两套拼装逻辑（Chat vs Text Completion）    → 01 页 §三
│   ├─ 出问题怎么定位（分诊，不是改措辞）
│   │   └─ 第一刀：这个值/行为是**谁写出来的**（解析环 vs 生成环） → 01 页 §七
│   │   └─ 第二刀：取证看它真正收到的（先知道看什么，再看）    → 01 页 §七
│   │   └─ 第三刀：让它指认看了哪段——**只能当线索不能当结论**  → 01 页 §七
│   │   └─ 分诊表：现象 → 先怀疑哪个环节                     → 01 页 §七

│
└─ L6 评估层：怎么判断好不好、怎么选
    └─ 各家模型脾气 + 服从度实测                          → 05 页
    └─ 主观作品怎么判：评"解决了什么问题"不评"比默认好多少" → 05 页 §五
    └─ 证据不足≠判定不行（挂起而非否决）                   → 05 页 §五
    └─ 群体反应粗筛 + 人评拍板 + 规则留松紧口子            → 05 页 §五

```

**四条铁律横跨全层**（它们不归属任何单一层，是所有层共同遵守的判断依据）：
位置>措辞 / 正面规定>负面禁止 / 不测不上线 / 模型不检查自己。

## 四条打地基的话

这四句是这段时间从十几份资料里磨出来的，后面所有新东西都要往上挂：

**第一句：放哪儿比怎么写更要紧。**
同一条规矩，开头写和结尾写，效果差着一个量级。SillyTavern 和 Anthropic 是完全不同的两套技术、两家公司，却独立给出了同一个答案——**长材料放开头，指令放最后**。两边都测出来能提升接近三成。这种巧合级别的印证，值得当成铁律记下来。

**第二句：说"要什么"比说"别怎样"管用。**
"要自然"只有一个方向可走，"别文绉绉"有一千种反面的写法。模型是照着"下一步动作"训练的，给它一个能执行的动作，远比给它一份禁止清单有效。

**第三句：没量过的提示词不算数。**
好不好用只能跑出来。看三个数：一次就对的比例、返工几轮、格式稳不稳。

**第四句：模型给自己打分不算数。**
这条是《天之下》项目用真金白银换来的——模型自报"已通过全部检查"的稿子，实际没通过。所以校验必须由**模型之外**的确定性程序来做：数汉字、grep 禁词、逐项打勾。这条不只适用于写小说，所有 AI 自动化的流水线都该这么干。

2026-10-10 这条铁律有了**实测样本**（30 章真跑一轮，详见 [[05-模型挑食实测-谁听话谁不听话]] 第五节）：有一章字数超出上限 45%，校刀报告里白纸黑字写了"超出上限，本轮特批"，判定栏写的是"合格（按允许保留放行）"。**所以铁律四真正的样子不是"模型会看错"，而是——只要改判的口子开着，硬规则就守不住。** 同一轮还测出：能取出自报数字的 13 章里，12 章的字数和脚本对不上（偏差最大 269 字），说明**凡是"有多少"这类计数，模型报的数连参考都不该参考**。

类脑社区的模型体感也印证了这条：DeepSeek 便宜但**容易丢格式**，Gemini 贵一点但格式稳。**格式保不干净是模型层面的毛病，只能靠外部脚本兜。**

## 本区写作规范（教学母版 v4 适配）

本区所有知识页**不写**"项目复盘长文"，但全部套用教学 v4 的底层原则（母规范见 [[通用教学提示词v4-项目复盘版]]，技术科目实例见 [[51单片机-教学法总纲]]）。下面八条是 v4 落到"常翻的参考页"上的版本——**改本区任何一页前先读它。** 适配思路：把 v4 的"代码/项目"换成"机制/结论"，把"模块"换成"节/页"。

### 八条页面铁律

**铁律一 · 动机先行。** 每页开头先讲"读完这一页你能干一件什么事"，每个大节先讲"为什么要懂这块、不懂会踩什么坑"。不铺垫动机直接上定义，等于把人推进没地图的房间。

**铁律二 · 锚定出处。** v4 的"锚定产物"在知识页里长这样：每条结论必须能挂回具体出处章节（官方文档某页 / 社区教程某节 / 我们自己项目的实测），并且配一句"按它做会怎样、不按会怎样"。三样缺一，这条不算讲透。

**铁律三 · 三层尺度。** 微观讲"这一步在机制里干什么"，中观讲"它和哪块对接"，宏观讲"整个提示词体系为什么需要它"。读者卡在哪层补哪层。

**铁律四 · 术语拆大白话 + 不跳步。** 每个新术语第一次出现，必给一句话人话 + 一个生活比方（摆摊、开店、公司群这种你本来就会的领域）。类比准入四条：逻辑链讲完才用、借自你已会的领域、标明"这只是感觉不是依据"、同一个类比用到底。**禁止用类比代替推导。**

**铁律五 · 反刍与三钩。** 一个核心概念全页至少见三次：第一次讲它在本地干什么，第二次回指（"还记得前面那块吗，它在这里又出现了，用法不一样"），第三次讲它在整个体系里的位置。每节开头必须有回看钩，每节至少埋一个钩给后面的节，全文至少三处平行钩（指出两节在做同一件事），最后收线解开。

**铁律六 · 结尾费曼题库。** 每页末尾 3 到 5 题，考"为什么"不考"是什么"。答案必须能在前文找到。三档配比：复述型三成、推导型五成、迁移型两成。答得出才算这页过关。

**铁律七 · 禁词。** 删掉"显然""众所周知""简单来说""只需要""不言而喻"，以及任何"跳过一步"的说法。

**铁律八 · 笔触。** 称呼用"你"；难点前给情绪预告（"下面这段是全页最绕的，慢一点"），过去补一句"过了，后面轻松"；长短句交替；纯文字段里最多一个新术语；每段收尾一句小结加一句过渡；每隔两三段回地图标一次位置（"现在讲的是第几层"）。

**铁律九 · 宁整合勿新建（防碎片化，最新加的一条）。** 一件事不许拆成多个散页或散节——新内容先按「体系架构」那张树找归属：能挂到已有页的对应小节就挂进去；同一页里若已有小节讲过同一件事，**合并进去而不是另起一段**；只有当一个主题**已成体系**（有 3 条以上互不重叠的子结论，且放任何已有页都别扭）才允许新建一页，一天最多 1 个。判断依据是那句老话：**新页 60% 内容已有页能找到 = 重复，必须合并。**

> 这条是血泪教训：2026-10-07 那天我一度把内容拆成"预设管理""自主循环""角色人格"多个分散小节堆进不同页，读者要翻五六个地方才看到一条完整线索。**页面要越读越厚、越来越连贯，不是越读越多。**

### 一页的标准骨架（顺序可微调，但五块不能少）

```
动机（你会学到什么 / 不懂会怎样）
  ↓
地基（这件事在机制里站哪）
  ↓
原理（核心机制，按三层尺度讲）
  ↓
实战（直接能抄的设置 / 代码 / 流程 / 默认值）
  ↓
坑（具体到现象，别写"要注意"这种空话）
  ↓
费曼题库（考为什么）
  ↓
关联 + 来源（含版权声明）
```

### 验收三级（由动作定，不由 AI 宣布）

- **L1** 看完能说清"这页讲了什么、挂在四条铁律哪条上"——必达
- **L2** 打开任意一节，能说出它和哪块对接、出处是哪——合格线
- **L3** 能答出"改这条规矩会波及哪里""从零自己搭一套按什么顺序"——目标
