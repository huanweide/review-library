## 五、core 一体化 PPT 文档能力（slides 形态落地）

「考试幻灯片」与「考点大全 / 考纲」同源协议，仅 `kind` 不同，不新增 action：

| 文件 | 改动 |

## 六、诚实边界与已知问题

1. **LLM 语义层需用户 API key**：本机 `RL_API_*` 为空、无 Ollama，core 的 slides/digest/syllabus 真模型生成无法在本机跑；PPT 改用 slidep 基于真实抽取内容直出，规避依赖且覆盖全资料。workbench 内点「生成考试幻灯片」会提示先配 API。
2. **旧 pptx 文件被 Windows 句柄锁**：`考试复习包.pptx` / `复习资料全量考试包.pptx` / `最终考试包.pptx` 三个旧文件因残留句柄无法删除（busy），无害残留，待系统释放或重启后可清。最终交付物为 `复习资料全量考试包_v2.pptx`。
3. **slidep 图片路径**：`<Image src>` 必须用**绝对 Windows 路径**（`C:/Users/...`）才能嵌入；相对路径解析不到。已据此修正 07 页。
