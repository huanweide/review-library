# 经验报告 · v0.7 复习闭环与数据完整性（整夜 maxloop）

> 适用：未来同类「产品深度迭代」轮次。结论可复核，来自模型之外的真实证据。

## 一、本轮做对了什么（值得复刻）

### 1. 双透镜 critic 比单轮自检多钉出 3 条隐藏真缺陷
上一轮 v0.6 只靠主代理自检，漏了「报告今日到期算错」「65MB 文件静默不进备份」「导入绕开锁」。本轮真实 spawn 两个只读 critic（用户视角 / 工程健壮性），各自带 file:line 锚点，直接钉出这 3 条 + 6 条产品缺憾。**结论：凡 maxloop 产品迭代，必须派独立 critic，且给它们不同的透镜（用户路径 vs 数据/安全），不要主代理自问自答。**

### 2. 判别测试「旧码必红」是防假绿的唯一护栏
`test/maxloop-v07.test.js` 在 v0.6.0 旧码上跑出 `1/31 红`，改完 `42/0`。中途我修了 4 条会「假绿」的判据（V2-2 / V1-4 / V4-7 / V6-4 / V9-5 / V7-10），全部是「旧码在新判据下仍是红」才放行。**结论：判别测试必须先取 baseline 红，且每条断言要能在旧码上失败；任何「改完直接绿」都要怀疑是不是判据放水。**

### 3. 四层 API 镜像一次接通 + 新 UI 专用 class，零回归
server.js / app/main.js / preload.js / api-client.js 四个入口同步；新 UI 一律 `.review-*` / `.feedback-history-*` / `.cloze-rate*` 专用类，不复用旧选择器语义。结果 e2e 旧 180 项无回归、新增 13 项直达断言。**结论：前端选择器抢语义是 v0.6 三次回归的根因，本轮用「新功能必起新 class」彻底规避。**

### 4. 全量跑而不是挑着跑
每次改完都 `npm test`（已改成遍历 test/*.test.js）+ 真浏览器 e2e，而不是只跑新套件。这是上一轮「改新功能弄坏旧语义」教训的落地。**结论：`scripts/run-tests.js` 这种统一入口是必须的，不能让 `npm test` 只跑一个文件。**

## 二、踩的坑（本轮新发生的）

### K1. 备份完整性契约缺失才是「数据悄悄丢」的真根因
不是某个函数写错，而是 `backup.js` 导出时「跳过不记账、恢复时把记录加回当成功」。修法是给备份加 `skipped[]` + `integrity{}` + UI 显式告警，并把上限从 64MB 提到 180MB。**反思：数据完整性问题要补「契约 + 显式反馈」，不能只补一处跳过。**

### K2. 统计口径被「展示截断」污染
`analytics.js` 从「lapse 前 12 条」算今日到期，而 `study.js` 用全量。两套口径是 v0.5→v0.7 反复出问题的同源。**反思：统计数据源必须是全量、单一权威函数（如 `study.isDue`），展示层再截断，不能反推。**

### K3. 复习被建模成「试卷附属」而非「独立事件」
四档自评强依赖 examId，导致挖空卡、独立闪卡都无法自评。修法是 `store.ratePoint` + `review.rateCard` 不依赖 examId、不改 history。**反思：自评/复习是一类一等公民事件，不应挂在 exam 底下。**

## 三、没做 / 打回的（按 R/C/N，理由透明）

| 项 | 决策 | 理由 |
|---|---|---|
| 倒排索引 | 打回 | 实测 local-first 倒排索引冷启动 9 秒（反面证据），当前资料量级顺序扫描够用；等资料量上来再上 |
| 考试日期排程 | 打回 | 需要可靠时钟 + 多时区，收益未到阈值 |

| 云同步 / md 双链 | 打回 | 破坏「本地优先/离线」铁律，且需账号体系 |

## 四、发布环节的血泪（务必记牢）

### P1. GitHub 发布依赖浏览器会话，会话过期就卡死
v0.6.0 能发是因为当时 Edge 会话活跃；本轮会话 Cookie（`user_session`）未持久化，调试实测 GitHub 返回登录页。本机 `gh` 令牌失效、凭据管理器/常见文件无 PAT。**结论：发布前先确认 `gh auth status` 或 Edge 会话有效；否则把「发布」显式列为需用户动手的一步，不要假装完成。**

### P2. 杀掉用户运行的 Edge 才能复用配置
真实 Edge 进程占用配置锁（SingletonLock），必须用 `--user-data-dir` 指向其配置（目录联接 `C:\EdgeProfileLink`）并以 `mklink /J` 复用；若 Edge 在跑，先 `taskkill /IM msedge.exe /F` 释放锁再重启带 `--remote-debugging-port`。**反思：夜间自动跑若需复用登录态，先确认目标浏览器没在跑。**
