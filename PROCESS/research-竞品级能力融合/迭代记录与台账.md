### 根因段 B（A 出错点 ≠ B 根因，同修）
- 功能缺口根因是两处**设计约定**：`README.md:65` 整体打回双链时误伤「知识点可视化」；`lib/store.js:393` 注释把「轻量」写成拒绝任何逐项状态量。→ 本轮同步修订 README 功能边界说明与 store 注释，不只补 UI。
- B1 根因：批改被建模成**可覆盖字段**、一次交卷被当成一次真实复习 → 修在数据入口与错题本写入两处，不改 `gradeExam` 纯函数（单测依赖其可重算）。
- B2 根因：共享单文件 JSON 被当单进程内存对象做 read-modify-write，每进程独立 `new Store()` 无协调 → 改写入范式（锁 + 原子替换），不是给某次写打补丁。

4. **考试日期驱动排程 / PDF 批注高亮**未做（G2/G3 打回）。
5. **真调视觉 API 仍需用户填支持视觉的模型**（本轮零外链，多模态全走注入 chatFn 验证）。
6. **全局搜索是顺序扫描**，上千本书时未做倒排索引；当前定位够用，超大库需再评估。
