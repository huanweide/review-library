# 一句话经验

**单测 173 项 + e2e 166 项全绿，照样藏着 7 条能让用户丢数据、让核心功能完全失效的缺陷。**
把这些缺陷逼出来的不是"更仔细地读代码"，而是**换判据**：从「mock 里的理想数据」换成「真实 Store 落盘数据 + 真实子进程」。

---

## 一、三个反直觉发现

### 1. mock 会把缺陷伪装成全绿

`test/study.test.js` 里 asset 的 mock 写 `ext: 'png'`，而 `store.addMaterials` 真实落盘是 `path.extname(an)` → `'.png'`。
`lib/study.js` 白名单写 `['png','jpg','jpeg']`。单测永远过，**真实 PPTX 一张图都发不出去**。

> 教训：凡「跨模块的数据格式契约」，测试必须用**生产侧真实产出的对象**，不能手写同构 mock。
> 本轮 `test/maxloop-regression.test.js` 的 D2 改成先 `new Store()` 真落盘，再读回 ext 做断言。

### 2. 死代码里还藏着死代码

`setAssetCaption` 没导出 → 从没被执行 → 它内部调用了一个**根本不存在的函数** `writeBookMeta`，还打算写错文件（`book.json` 而非 `materials.json`）。
只读走查只报了"未导出"；判别测试第一次真正调用它，立刻 `ReferenceError: writeBookMeta is not defined`。

> 教训：把"导出/接线"补上之后**必须立刻跑一次真实调用**，否则只是把 bug 从「不可达」变成「可达」。

### 3. "修好了"的绿可能是关键词口径的绿

D3b 断言「降级后不再命令模型读图」，首轮修完仍红。探针显示残留命中全是
`禁止输出 assetRefs`、`不要输出 imageCaptions` 这类**否定句**。
两种做法：放宽断言（假绿），或按基准「never hand the model a sentence it can turn into a lie」把字段名从降级提示词里彻底拿掉（真改进）。选了后者。

> 教训：断言红的时候先分清「产品没修对」还是「断言口径不对」，别顺手放宽断言。

## 二、可复用的方法（下次直接用）

| 场景 | 做法 | 本轮证据 |
|---|---|---|
| 找测试覆盖不到的真缺陷 | critic 只读探针 + **真实 Store / 真实子进程**，要求文件:行号 + 可复现命令 | 5 条带锚点，Chair 用 `sed -n` 逐字符复核 |
| 证明修的是真问题 | 判别测试先在旧版跑红再新版跑绿，两次输出都留痕 | baseline `1/10` → candidate `11/0` |
| 防止"只修源码、产物没修" | 从 `app.asar` 解出 lib，**用解出的代码跑行为测试** | `scripts/verify-asar-behavior.js` 5/0 |
| 融合外部优点 | 对照表 + R/C/N 决策表，明确写「不融合」的理由 | 采纳 F1-F7，打回 FSRS/SQLite/云同步 |
| 降级类改动 | 必须换整套结果契约（system prompt + user text + 结果字段 + UI 披露），不是少发几个图块 | D3 四条断言 |

## 三、项目特有的坑（已写进脚本注释）

1. 中文路径 → NSIS/7za 崩，构建要复制到纯 ASCII 目录（`scripts/build-win.js`）。
2. 宿主环境 `ELECTRON_RUN_AS_NODE=1` → Electron 退化成纯 Node、打包 exe 静默退出且无报错（`scripts/verify-packaged.js`）。
3. Node `fs.cpSync` 在「路径含空格 + 中文」时静默失败只复制空目录 → 改 `robocopy`。
4. `spawnSync` 传 `shell:true` 拼字符串，路径含空格会被拆断 → 用 `process.execPath` + 数组参数直调本地 CLI。

## 四、诚实边界

- 本轮所有多模态验证用注入的 `chatFn`，**没有真调外部视觉 API**（零外链纪律）。M3 在真实服务商上的效果仍需用户填支持视觉的模型后验收。
- C（GitHub 上传版本）仍待建仓：`gh` token 失效、github 连接器 disabled；SSH 认证已通。
- 未找到可证伪的目录穿越 / CSP 绕过 / 密钥泄漏 / HTTP-Electron 契约缺失，critic 逐项给出「找不到」，不凑数。
