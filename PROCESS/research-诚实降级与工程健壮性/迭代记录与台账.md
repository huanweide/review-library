## 阶段二/三 · R/C/N 台账

| 改动 | R 合理性 | C 正确性（锚点） | N 必要性 | 根因段 B | 结论 |
|---|---|---|---|---|---|
| 回收站父书存活校验 + 连带恢复 | 与「真落盘可恢复」定位一致 | 旧版实跑 `err2=ENOENT / books=0 / trash=["book"]` | 不改＝不可逆数据丢失 | 恢复操作缺父实体存活校验 | 过关 |
| `restoreBook` 幂等 + 幽灵目录合并 | 同上 | 同上；防止连带恢复后重复点恢复报错 | 不改＝修完主路径仍卡历史脏数据 | 同上 | 过关 |
| `normExt()` 归一 | 与 M3 契约一致 | 探针 `落盘 ext=".png"` vs 白名单 `png`；`readAsset OK` | 不改＝真实 PPTX 图全丢 | 落盘/消费无共用归一函数 | 过关 |
| 双 system prompt + 双 userText | 与「不造假」铁律一致 | D3b 旧版实跑 `第2次请求仍要求读图: true` | 不改＝模型编图说明 | 降级没换结果契约 | 过关 |

| 收窄 `isVisionUnsupported` | 与降级语义一致 | 原正则含裸 `400` / `bad request` | 不改＝合法 400 被静默吞 | 判定过宽 | 过关 |
| 导出 `setAssetCaption` 并改读写 materials.json | 与自身读接口契约一致 | 旧版 `typeof=undefined`；导出后 `ReferenceError: writeBookMeta is not defined` | 不改＝写回必失败被吞 | 死代码无执行约束 | 过关 |

| G1 FSRS-6 / G2 SQLite向量库 / G3 云同步插件 | 相关 | 竞品确有 | **打回**：超定位、引依赖、破坏离线零外链 | — | 不融合 |

## KNOWN-LIMITATION（显式交接）

1. 真·调用视觉 API 仍需用户填支持视觉的模型；本轮所有多模态验证走注入 chatFn 与真实 Store，不代调外部 API（零外链纪律）。
2. C（GitHub 上传版本）仍待建仓：`gh` token 失效、github 连接器 disabled，SSH 认证已通。
3. 历史遗留的幽灵书目录有兜底合并，但「目标已是完整书目录 + 回收站仍有同名书」的异常态保留 src 原地不静默删，需人工 `purgeTrash` 或介入。
4. 纯图资料在 `useVision=false` 下仍明确拒绝（合理：没开看图就没材料），文案已给可执行下一步。
