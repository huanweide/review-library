# 明早汇报 · 考纲思维导图 v0.8（斯瑞）

## 一、这轮做了什么

把「考纲」从**死树**升级成**可探索知识网络**，新增「思维导图」模块（考纲 tab 旁）：

- **中心辐射**：每节一张中心图（晶体一张、石墨一张），中间是中心知识点、四周辐射子知识点，SVG 节点+连线。
- **无限嵌套**：点任一节点 → 右侧栏出 summary；有子类型就出「子类型」按钮，点开继续往下钻，可层层展开，并列出该节点挂靠的例题。
- **题型分类面板**：某题型在某节点下只有 1 题时，自动进右侧「题目分类」面板，点开看题+答案+解析；多题题型留在节点卡片内。
- **跨知识点双链**：同一道题考到的两个知识点互相 `related`；点关联按钮直接跳到另一张图对应节点。
- **LLM 可自行生成详解**：填了 API 就「用我的 API 生成详解」补 summary/子类型/关联；没填走「规则版重建」，骨架来自考纲.md + 题库.json。

## 三、现在你可以怎么用

1. 打开一本书 → 点「考纲」旁边的「思维导图」tab。
2. 点「规则版重建」（基于你上传的考纲.md + 题库.json 自动生成）→ 等待几秒。
3. 点中心图上的任一节点 → 右侧看解释/子类型/例题；单题题型在右侧「题目分类」面板；有关联的知识点可一键跳。
4. 想在节点里看到大模型写的更细解释与子类型：去「设置」填 API，回来点「用我的 API 生成详解」。
