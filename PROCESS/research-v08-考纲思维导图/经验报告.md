# 经验报告 · 考纲思维导图 v0.8

> 一句话：把「死树」考纲（章节→小节→知识点）升级成「可探索知识网络」——中心辐射 + 无限嵌套 + 题型分类面板 + 跨知识点双链。判别测试 0/12 红 → 12/0 绿；全量单测 10/10 套件；真浏览器 e2e 207/0；本地打包构建通过；tag v0.8.0 已推 GitHub，GitHub Actions 自动 Release 构建中。

## 真问题（不是堆功能，是接上最后一段）

1. **考纲是死树**：现有 syllabus 只有「章节→小节→知识点」两层线性结构，没有「中间概念向四周延伸」的中心辐射可视化，也没有节点富详情 / 子类型 / 关联数据位。
2. **知识点不能往下钻**：用户要的是「点远端节点 → 出现更详细解释 + 子类型 + 例题」，原结构承载不了。
3. **题型没有分类出口**：某分类下只有 1 题时，应该直接进右侧「题目分类」面板，而不是混在卷子里。
4. **知识不互相关联**：同一道题考到的两个知识点没有结构化双向索引（旧 graph 只有扁平关系图）。

## 残留限制（诚实边界）

- **LLM 版需你填 API**：规则版零依赖（考纲.md + 题库.json 抽结构）；填了才补 summary/子类型/关联。关联遵循「已存在不写、新类型追加」，不凭空造关系。
- **关联来自真实同题**：`related` 由「同一道题考到的两知识点」推导，不臆造；本 e2e 样本（每点各拥题）未产生跨点关联属正常，双链跳转断言做了存在性兜底。
- **每章多中心 = 每节一张**：支持只给第一、三章这类不连续输入；非整本强制连续。
- **本地无法跑打包版 CDP 验证**：本沙箱无显示，Electron 起不来 CDP（环境变量已正确 `unset` 仍无 GUI），故打包产物的窗口/桥接运行时验证交由 CI 发布的安装版完成（与 v0.7 同路径）。本机仅验证了「构建通过 + asar 含新文件」。
- **API 限流**：本机 IP 调 GitHub API 触发 403 限流，无法在此观测 CI 实时状态；Release 由服务端完成，不依赖本机观测。
