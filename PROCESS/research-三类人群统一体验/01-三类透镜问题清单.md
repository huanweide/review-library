## 一、透镜 A · 备考大学生（critic 报告 + Chair 亲验）

外部基准（GitHub API 实时）：Anki `ankitects/anki` **33,057★** —— "Anki is a smart spaced repetition flashcard program"；SiYuan `siyuan-note/siyuan` **47,433★** —— 块级引用与双向链接。来源见各 agent 报告原文。

**P1 · 147 道原题卡做成了一个「只读陈列馆」**（最贵的问题）
- 亲验：`library/books/87763d2d14a660d0/cards/` 下 **23 个 JSON 文件 / 147 道题**；`grep -rl '"options"' → 0`、`"rationale" → 0`、`"pitfalls" → 0`。
- 学生真路径：拿到课后作业 → 想做原题 → 题卡点了只能看，选不了、判不了分、不进 SRS；能判分的只有 12 道 LLM 自编题。
- 根因不是缺模型能力，是**生产端没产出结构化字段**：`build-lesson-cards.mjs` / `build-assignment-cards.mjs` 生成的是 title/content 文本卡，不是 options/answer 题卡。

**P2 · 24 份课件零文本层，全书靠 OCR 转录**：`corpusCoverage` 24/24 均为零文本，528 页靠视觉转录 17.2 万字。这是资料类型决定的，不算 bug，但意味着「换书」成本很高——一份新书要重跑转录 + 分析。

**P3 · 没有考前「小抄」产物**：全仓 `grep 小抄|cheatsheet` 零命中。学生考前要的是「一页纸」，现在只有 19 页幻灯片 + 复习总纲，都不是可打印的浓缩件。

**P4 · 作业卡埋得太深**（11-27 Chair 亲验纠正）：初判「界面不可达」是**假阳性**——真机没点进「题型」页签。实测 5 份作业组就在题型页最底部（3/3/2/7/7=22 题），但混在 27 个折叠组里、默认全收起，学生得滚到底再逐个展开才看得到。第 3 项据此从「从 API 走到界面」修正为「提升为独立页签 + 默认展开」。

## 三、透镜 C · 存储知识点考点（critic 报告 + Chair 亲验纠错）

外部基准：SiYuan **47,433★**（块级引用 + 双向链接）；Anki **33,057★**（"sync and backup" 官方能力）。

**P1 · 备份白名单漏字段**：`lib/backup.js:22` SETTINGS_KEYS = `['engine','baseURL','model','pointCount','questionCount','prompt','dedupeThreshold']` —— 漏 `visionModel`、`deepDive`、`tickEveryRounds`。换了机器，这些设置静默回默认。
- **纠错**：agent 说「上限 64MB」是错的；`lib/backup.js:20-22` 现行 **180MB**，注释明写旧版 64MB 会静默丢扫描版 PDF。

**P2 · 全局搜索有硬上限且无跨书聚合视图**：`lib/search.js:7` `LIMIT_DEFAULT = 80`，`:20` `Math.min(300, ...)`，`:88` 到限就 break。真机：搜索入口在顶栏「⌘ 搜索」，但结果到 80 条截断，用户不知道被截。
- **纠错**：agent 说默认 30，实际 **80**。

**P3 · 无自动备份**：全仓 `grep setInterval.*backup|定时备份|自动备份` 零命中。备份只能手动导出，`library/` 又 gitignore，机器故障＝全丢。

**P4 · 复习进度绑在 LLM 自编题上**：`core/practice.js:30-37` questionKey = SHA256(题面 + 选项 + 答案)。147 道原题卡无 options/answer，进不了这个哈希——学生做过题的记忆曲线只覆盖那 12 道自编题。

## 四、三者冲突点（统一计划必须同时解开）

| 冲突 | A 备考 | B 梳理 | C 存储 | 解 |
|---|---|---|---|---|
| 结构归谁 | 要模型给好结构 | 要人能改结构 | 要改动能存住 | 用户结构层：模型树为底稿，人工改动另存、不覆盖 |
| 题卡形态 | 要做题判分 | 要挂到知识点 | 要稳定 key 进 SRS | 题卡结构化（options/answer/rationale/pitfalls）+ 挂 pointPath |
| 产物形态 | 要一页纸 | 要可导出复用 | 要可备份 | 一份「考点包」同时是打印件、导出件、备份件 |
| 扫描版成本 | 要新书快 | 要结构准 | 要原图不丢 | 转录一次落盘，原图 SHA 去重（已有），新书只跑增量 |
