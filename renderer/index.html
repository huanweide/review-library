② API 连接

填之前先看清三件事（大白话）

1. 选云端引擎后，你勾选的资料文字会发到上面这个地址，由那家模型处理。发什么、发给谁，由你填的地址决定，本程序不替你选服务商。

2. 调用会产生你自己的 API 费用。建议先在服务商后台设一个消费上限。

3. 密钥只存在当前浏览器标签页（关掉标签页就没了，下次要重填），不写进项目文件、不写日志、不上传、不出现在截图里。公用电脑别填。其余设置（地址、模型名、参数）会记住，密钥不会。

③ 出题参数

去重阈值＝两道题的题干要多像才算重复。调高（如 0.95）只合并几乎一模一样的；调低（如 0.7）合并更多近似题，但可能误删本来不同的题。默认 0.82，改完重新分析才生效。云端的校验与重试固定开启，不需要配置。

④ 应用与更新

检查更新 / 桌面快捷方式仅在打包后的安装版（NSIS 安装器）中生效；开发模式与单文件 portable 版不启用自动更新。自动更新从 GitHub 发布页拉取，需要联网。

⑤ 数据备份（全在本地）

备份是单个 JSON 文件，含全部书、资料原件、分析结果、试卷与错题本。恢复会覆盖当前数据目录里的书，执行前会再确认一次。全程不发网络请求。
