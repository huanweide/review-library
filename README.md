# 复习资料图书馆

项目级**离线**复习资料管理与学习系统（v0.6）。一句话定位：

> 一本「书」= 一项考试 + 一项科目 + 其资料分析。可以有成百上千本书；书架即收录；每本书按层组织资料，层号越小越重要、参考价值越强。资料能分析、能出题、能批改、能针对薄弱点巩固；生成过程的质量对用户可见。

## 核心理念（来自需求）

- **分层图书馆，不是资料堆**：每本书是独立、自包含的一套。打开一本书 = 进入它自己的世界（书名 / 考试 / 科目 / 分层资料 / 分析结果 / 试卷）。书与书互不串。
- **分层机制**：L1 = 期末提纲 / 总复习 PPT（**可缺失**）；L2 = 作业；L3+ = 用户自定义。越上层越重要、参考价值越强。
- **每本书两类来源**：用户上传的资料 + 系统生成的参考资料（`source` 字段区分）。
- **真落盘、可增删**：成百上千份资料真实存到磁盘，随时查看 / 新增 / 删除 / 分类；删除进回收站可恢复或彻底删除。
- **零外链、离线优先**：前端所有解析库落本地 `renderer/vendor/`；顶层 CSP 的 `connect-src 'self'` 从浏览器层面禁止直连外部域名。想用云端模型时，也只由本地服务/Electron 主进程转发，前端永远只打同源 `/api`。

## 四种运行方式

| 方式 | 怎么启动 | 数据放哪 |
|---|---|---|
| **A. 本地服务（推荐先试）** | 双击 `启动.bat`，浏览器开 `http://localhost:5178` | 项目内 `library/` |
| **B. 单文件 exe（最省事）** | 双击 `dist/ReviewLibrary-0.6.0-portable.exe` | exe 同级 `library/` |
| **C. 免安装桌面版** | 双击 `启动桌面版.bat`，或 `npm run build:dir` 后运行 `dist/win-unpacked/ReviewLibrary.exe` | exe 同级 `library/` |
| **D. 开发模式** | `npm start`（需先 `npm install` 拉 electron） | 项目内 `library/` |

四种模式共用同一套落盘逻辑 `lib/store.js`，前端 `renderer/js/api-client.js` 自动适配 Electron ipc 与 http `/api`。想指定数据目录：设环境变量 `REVIEW_LIBRARY_ROOT`（server 模式也支持 `LIBRARY_ROOT`）。

## 设置系统与双引擎

顶部「设置」页有三块：

1. **分析引擎**：`本地引擎（默认）` / `云端引擎`。不填任何东西就能完整用；填了才走云端。
2. **API 连接**：`API 地址`（填到 `/v1` 那一级）、`API 密钥`、`模型名`，配「测试连接」与「一键清空密钥」。走 OpenAI-compatible 通用格式，不绑定厂商（官方、国内聚合、本地 Ollama 都能填）。
3. **出题参数**：知识点数量、每张卷题目数、**题目去重阈值**、默认复习要求提示词。

两个引擎吐**同一种结果格式**，前端不分辨谁算的：

| | 本地引擎 | 云端引擎 |
|---|---|---|
| 联网 | 完全离线、零外链 | 调用**你填的那个地址** |
| 怎么出结果 | 按层权重 + 提示词关键词从资料原文抽重点，规则出题 | 大模型按提示词分析资料、生成四类题 |
| 会不会编内容 | 不会，只摘原文；模板题明确标 `AI补充` | 提示词强制「材料未覆盖必须写明、不许编造」，**外加本地校验与有限重试** |
| 费用 | 0 | 你自己的 API 费用（重试最多多一次调用） |

> **云端引擎是大白话说清的，不是默默发生的**：设置页写明「你勾选的资料文字会发到你填的地址」「会产生你自己的 API 费用」「公用电脑别填」。

### 密钥怎么保管（三铁律）

- 密钥**只进当前浏览器标签页的 `sessionStorage`**，关掉标签页即失效，下次重填。地址、模型名、参数才进 `localStorage`。两者物理分开。
- 不写进任何项目文件、不写日志、不上传、不出现在错误回显与截图里。`lib/llm.js` 的 `scrub()` 会把密钥和 `sk-` 长串抹掉。
- 本地引擎**根本不把密钥发到后端**；只有选了云端才传，且只在单次请求的内存里出现。

## 分析与出题闭环（融合 ko-lesson）

参考 `Liunian06/ko-lesson`（约 431 star，MIT）的 README 与 SKILL.md 原文，采纳六项、打回七项，逐字符证据与 R/C/N 决策见 `PROCESS/research-app-设置与分析/best-practices.md`。

**书内三个子页：资料 / 分析 / 练习。**

1. **先划材料边界**：分析前列出本次纳入哪些资料、每份在课程里承担什么作用、明确排除哪些。没勾的不会被偷偷读。
2. **分析结果**：知识点卡片 + 题目预览 + **生成质量报告**。**来源依据**（绿）标文件名 / 位置 / 用法；**AI补充**（橙）明写「材料未直接覆盖，非原文」。不把补充内容伪装成原文。
3. **审阅后保存**：结果不会自动进库，你点「审阅后保存」才落盘。
4. **出题**：四类题型（单选 / 多选 / 概念解释 / 综合应用），不只考记忆。**试卷只放题目，交卷前页面上不出现任何答案**。
5. **批改**：正确 / 部分正确 / 错误三判定，标错因类型，给标准答案、详细解析、常见错误、来源引用。
6. **巩固卷**：只针对错误与薄弱知识点，且**每个薄弱知识点只出 1 题**，不机械重复整套。循环到全对为止。
7. **反馈五问**：我能复述的 / 我卡住的 / 难度 1-5 / 希望下一步 / 联想到的已学内容。

打回的：Obsidian 双链与 md 文件体系、逐课生成、故事模式、一课一知识点、截图逐字 OCR、PBKDF2 主密码加密（对零基础用户负担过大）。「题目去重 / 幻觉重试」在 v0.4 曾被打回，**v0.5 已转正**，见下一节。
> v0.6 澄清边界：这里打回的是「把知识库整体改成 md 双链文件体系」，**不是「知识点可视化」**。v0.6 已用分析结果内的知识点关系图（本地 SVG）补上后者，不改落盘格式、不引入 md 文件体系。

## 出题质量保障（v0.5 新增）

依据 4 组真实项目检索、23 条逐字符锚点（`PROCESS/research-出题质量增强/best-practices.md`）。核心判断：**校验器是本地代码，不是让模型自评有没有幻觉**——CRITIC 与 Huang et al.（ICLR 2024）都证明无外部反馈的自我纠错不可靠。

| 环节 | 做法 | 依据 |
|---|---|---|
| 分层去重 | 题干归一化 → SHA256 精确指纹 → 字符 bigram + Jaccard 近似 → 阈值可配（默认 0.82）→ **返回重复对、原件保留不静默删** | `DejaText`、LobeHub Content Deduplication |
| 本地可执行校验 | 只判关于草稿本身的结构事实：来源文件是否落在本次材料边界内、`AI补充` 是否写明未覆盖、字段是否为空、知识点是否悬空、答案是否越出选项 | CRITIC、Agent Reflection「controller 由代码写」 |
| 有限重试 | **由代码控制循环**，预算固定 1 次；把上一轮校验问题回给模型并把温度降到 0；保留见过的最佳草稿，绝不返回更差一版；返回停止原因 | `self-healing-rag`、`clinmesh` 额度纪律、RAGAS 低分修复建议 |
| 诚实降级 | 预算耗尽后剥除未核验的来源、把相关题强制标为 `AI补充` 并显式告知；为空则**大声失败不造空卷**。不猜、不静默放行 | `self-healing-rag`「honest fallback instead of guessing」 |
| 过程可见 | 结果页「生成质量报告」卡：去重前后题数与重复对、校验结论与得分、生成轮次与停止原因、可展开的每一步校验轨迹 | `self-healing-rag` trace panel |

**默认本地引擎也有质量报告**（去重 + 校验全跑，零重试、离线零成本），不填 key 也能亲眼验证。云端链路的重试与降级用可注入 mock 做判别测试，**测试全程未发任何真实外部请求、未使用真实密钥**。

## 其它功能

### 资料管理
收录书 / 删除并恢复书、按层导入任意文件、拖拽上传、按层筛选、移层、删除进回收站、恢复资料与整本书、彻底删除。

### 组合检索
来源 / 标签 / 时间 / 类型 四个维度与**关键词**、**左侧层筛选**六者同时生效（AND），实时显示「命中 X / 共 Y」，一键清空。

### Office / 文本浏览器内预览
| 格式 | 做法 |
|---|---|
| PDF、图片 | 原生 `<iframe>` / `<img>` |
| `.docx` | mammoth.js 转语义 HTML → DOMPurify 清洗 → `sandbox=""` 的 `iframe srcdoc` |
| `.xlsx/.xls/.csv` | SheetJS `sheet_to_html` → 清洗 → 同上 |
| `.txt/.md` | 转义后本地预览 |
| `.pptx` | 抽取每页文字做纯文本预览（**不做版式还原**），保留下载兜底 |
| `.doc/.ppt` | 明确提示另存为 `.docx/.pptx` 后下载 |

大于 8 MB 的 docx/xlsx 解包放 Web Worker。安全三层：解析库输出一律 DOMPurify 清洗 → 禁脚本 `sandbox` iframe → 顶层 CSP 锁死外部网络。

### 本地提示词驱动的系统参考资料
书内「生成复习提纲」按层权重 + 关键词从已落盘资料抽原文片段，产出 markdown 提纲，作为 `source:'system'` 资料落 L1 并回链来源。不联网、不调模型、不产生新知识点；没有命中就明确失败，不造假。

### 真实资料种子
`scripts/seed-library.js` 把工作区**已有真文件**按层导入，不编考纲 / 题目 / 答案：工程材料（考纲 md / 讲义 / 86 题题库 / 229 考点索引）与概率统计（正态分布答案 md+docx / 四张真实图片），两本书 12 份。按书名判重，可重跑。

```bash
node scripts/seed-library.js
LIBRARY_ROOT=xxx node scripts/seed-library.js
```

## 已知限制（v0.5）

- **云端引擎会把资料文字发到你填的地址，并产生你自己的 API 费用**（重试最多多一次调用）。设置页已用大白话写明。不填就是纯本地。
- **密钥存 sessionStorage**：关标签页要重填；共享电脑 / 本机恶意软件仍可能读到内存中的密钥（没做主密码加密）。
- **本地引擎不产生新知识**，只做规则抽取与模板出题，质量低于大模型；多选与综合应用题明确标 `AI补充`。
- **本地校验只判结构事实**，判不出「把原文改写成似是而非的错误结论」；真正的语义 Faithfulness 需要 LLM-as-judge，会额外花钱，未做。**词法去重抓不到语义改写**（"cat" vs "feline"），阈值 0.82 是经验值不是最优值。
- 云端重试**固定最多 1 次**，用完即降级或显式标注，不会无限自我修正。
- **截图 OCR、语义嵌入去重、树形无限层级分类**未做（当前是「书 → 固定层号 → 资料」三层）。
- **单文件 exe 重新打包需纯英文路径**（本机 github 无 DNS + 中文路径致 NSIS 内存映射崩）。日常使用不受影响。证据见 `PROCESS/research-项目级增强/放弃报告-单文件exe.md` 第七节。
- Office 版式不是 100% 还原。
